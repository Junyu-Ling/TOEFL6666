# 双记忆法功能说明

## 功能概述

每个单词答错后，AI会自动生成**两种不同类型的记忆法**：

1. **词根词缀记忆法** - 系统拆解单词结构
2. **谐音记忆法** - 有趣的中文谐音联想

学生可以通过点击**"切换"按钮**在两种记忆法之间切换，选择最适合自己的记忆方式。

## 使用方法

### 1. 触发记忆法生成

- 在单词卡片中答错单词
- AI会自动生成两种记忆法

### 2. 查看和切换记忆法

记忆法会显示在卡片底部，包含：
- 记忆法类型标签（词根词缀 / 谐音）
- 记忆公式
- 详细说明
- **切换按钮**（右上角）

点击"切换"按钮即可在两种记忆法之间切换。

### 3. 切换按钮显示

```
【词根词缀】 un(不)+willing(愿意) → unwilling  [🔄 切换 1/2]
这是一个否定前缀的经典例子...

↓ 点击切换按钮后 ↓

【谐音】 unwilling 谐音「俺未零」  [🔄 切换 2/2]
想象自己还未到零分，不愿意继续...
```

## 记忆法类型说明

### 词根词缀记忆法 (root)
- 颜色：紫色标签
- 适合：系统学习，理解单词构成
- 内容：前缀+词根+后缀拆解
- 例子：`un(不) + will(意愿) + ing → unwilling`

### 谐音记忆法 (homophone)
- 颜色：橙色标签
- 适合：快速记忆，趣味联想
- 内容：中文谐音 + 场景联想
- 例子：`abandon 谐音「阿笨蛋」→ 笨蛋被抛弃了`

## 技术实现

### 后端 AI Prompt

```javascript
// server/ai-memory-trick.js
必须生成两种记忆法：
1. 第一种：词根词缀 (type: "root")
2. 第二种：谐音联想 (type: "homophone")
```

### 数据结构

```json
{
  "memory_trick": { /* 第一种记忆法（兼容旧格式） */ },
  "memory_tricks": [
    {
      "type": "root",
      "formula": "un(不)+willing(愿意) → unwilling",
      "content": "un- 是否定前缀..."
    },
    {
      "type": "homophone", 
      "formula": "unwilling 谐音「俺未零」",
      "content": "想象自己还未到零分..."
    }
  ],
  "pronunciation_alert": "读音提示（如有）"
}
```

### 前端组件

```jsx
// src/components/MemoryTrickBlock.jsx
<MemoryTrickBlock 
  trick={result.memory_trick}      // 单个（兼容）
  tricks={result.memory_tricks}    // 数组（新功能）
/>
```

## 存储位置

记忆法数据存储在：
- **FlashCard**: `result.memory_tricks`
- **WordList**: `item.memory_tricks` 
- **LocalStorage**: 自动保存用户进度

## 注意事项

### 首次使用

1. **旧的记忆法数据**只有一种，不会显示切换按钮
2. **新生成的记忆法**会自动包含两种，显示切换按钮
3. 如需清除旧数据，可清除浏览器LocalStorage

### 切换状态

- 切换状态**不会**保存，每次重新打开单词都从第一种开始
- 这是为了让学生每次都能看到两种记忆法，反复对比选择

### AI生成质量

- 词根词缀法：优先拆解常见词根，若无则用词源或同根词
- 谐音记忆法：力求自然贴近词义，避免生硬联想
- 每种记忆法控制在100字以内，简洁实用

## 常见问题

### Q: 为什么我看不到切换按钮？

A: 可能原因：
1. 这是旧的记忆法数据（只有一种）
2. AI生成失败，只返回了一种记忆法
3. 重新答错单词让AI重新生成

### Q: 切换按钮不工作？

A: 检查：
1. 浏览器控制台是否有错误
2. 刷新页面重试
3. 清除LocalStorage后重试

### Q: 两种记忆法质量如何保证？

A: AI prompt中明确要求：
- 词根词缀法：拆解要准确，说明要实用
- 谐音记忆法：谐音要自然，联想要贴近词义
- 两种都要能真正帮助学生记住单词
