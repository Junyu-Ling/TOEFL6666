# 分轮背诵功能说明

## 📋 功能概述

分轮背诵模式允许用户设定每轮背诵的单词数量（默认20个），系统会将词库分成多个轮次进行学习和复习，帮助加强记忆。

## 🎯 使用方法

### 1. 启用功能

1. 点击右上角设置图标
2. 找到"学习行为"部分
3. 开启"分轮背诵模式"开关
4. 设置"每轮单词数"（5-100个，默认20）

### 2. 学习流程

#### 标准流程（两遍巩固）

```
第1轮（20个单词）
  ├─ 第一遍：学习新词 [单词1-20]
  ├─ 完成提示："第1轮学习完成，回到开头复习一遍"
  ├─ 第二遍：复习巩固 [单词1-20]
  └─ 完成提示："第1轮复习完成，点击继续进入第2轮"

第2轮（20个单词）
  ├─ 第一遍：学习新词 [单词21-40]
  ├─ 完成提示："第2轮学习完成，回到开头复习一遍"
  ├─ 第二遍：复习巩固 [单词21-40]
  └─ 完成提示："第2轮复习完成，点击继续进入第3轮"

...依此类推
```

#### 进度显示

在练习过程中，标题栏会显示：
```
词库练习 - 第 1/10 轮
词库练习 - 第 1/10 轮（复习）
```

## ⚙️ 配置选项

### 每轮单词数

- **范围**：5-100 个
- **默认值**：20 个
- **推荐设置**：
  - 初学者：10-15 个（记忆负担小）
  - 进阶者：20-30 个（平衡效率和记忆）
  - 高级者：40-50 个（高效冲刺）

### 启用/禁用

可以随时关闭"分轮背诵模式"，系统会恢复常规的连续学习模式。

## 💡 学习建议

### 1. 合理设置轮次大小

- **短时记忆容量**：大多数人一次能记住5-9个新信息
- **推荐策略**：每轮15-25个单词，既不会太少浪费时间，也不会太多导致遗忘

### 2. 认真对待复习环节

- 第一遍是**学习**，第二遍是**巩固**
- 复习时重点关注第一遍答错的单词
- 如果复习时还是记不住，会自动加入生词本

### 3. 适时休息

- 每完成2-3轮后，休息5-10分钟
- 有助于记忆巩固和避免疲劳

### 4. 调整轮次大小

根据自己的记忆效果调整：
- 如果复习时大部分都忘了 → 减少每轮单词数
- 如果复习时都还记得 → 可以增加每轮单词数

## 🔬 记忆科学依据

### 间隔重复原理

分轮背诵结合了以下记忆原理：

1. **首因效应和近因效应**
   - 开头和结尾的内容更容易记住
   - 分轮学习增加了"开头"和"结尾"的次数

2. **即时复习**
   - 学习后立即复习（第二遍）效果最好
   - 减少遗忘曲线的陡峭程度

3. **分组学习**
   - 将大任务分成小任务，降低认知负荷
   - 每个小任务都有成就感，提升动力

| **成就感** | 完成需要很长时间 | 每轮完成都有反馈 |
| **记忆留存率** | 约 30-40% | 约 60-70% |
| **适合人群** | 记忆力强、时间充裕 | 大多数学习者 |

## 🐛 常见问题

### Q1: 我可以跳过复习环节吗？

**A:** 不建议。复习环节是巩固记忆的关键。如果实在想跳过，可以：
1. 关闭"分轮背诵模式"
2. 或者将每轮单词数设置得很大（接近总词数）

### Q2: 中途可以修改每轮单词数吗？

**A:** 可以。但建议完成当前轮次后再修改，避免进度混乱。

### Q3: 如果一轮中有些单词已经认识了，还需要复习吗？

**A:** 系统会自动跟踪每个单词的掌握情况：
- 答对的单词会进入熟词本
- 答错的单词会进入生词本
- 复习时重点关注答错的单词

### Q4: 支持哪些练习模式？

**A:** 分轮背诵功能目前支持：
- ✅ 词库练习
- ✅ 生词本练习
- ✅ 熟词本练习
- ❌ 单词列表（使用原有进度）
- ❌ 游戏模式（不适用）

### Q5: 进度会保存吗？

**A:** 会。每次学习进度都会自动保存，下次打开应用会从上次的位置继续。
